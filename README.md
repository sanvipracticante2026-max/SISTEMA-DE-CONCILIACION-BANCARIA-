# Sistema de Conciliación Bancaria

Proyecto desarrollado en Python para automatizar la conciliación bancaria mediante archivos Excel.

## Objetivo
Comparar los movimientos contables con los extractos bancarios, identificar coincidencias, diferencias y movimientos pendientes.

## Características
- Lectura de archivos Excel.
- Comparación de movimientos bancarios y contables.
- Identificación de diferencias.
- Detección de posibles coincidencias.
- Generación de informes en Excel.
- Supervisión y validación humana.
